TOLY'S THEOREM

On the rug probability of infinitely many Percolator forks.

Statement

Let F be the set of all Percolator forks and C the set of all coins. Then:

P( ∀ f ∈ F : rug(f) ) = 1  ⇔  ∀ c ∈ C : rug(c)

First stated by @toly, 10 Nov 2026, in reply to a fork. Offered without proof. We supply one.

Proof

  1. (⇐) Suppose every coin is a rug. Every fork ships a coin within about four minutes (empirical). So every fork is a rug.
  2. (⇒) Suppose every fork is a rug. Forking costs nothing, so F is unbounded. For any coin c there is a fork that launches c. That fork is a rug, so c is a rug.
  3. Both directions hold. The engine appears on neither side of the equation.
Q.E.D. ■

Corollaries

  1. If one honest coin exists anywhere, at least one honest fork exists. We do not know which. Neither do you.
  2. You cannot tell a fork from its coin. You can tell it from its engine, because the engine can be diffed.
  3. $PPP is a rug if and only if all coins are rugs. It is a memecoin and can go to zero either way.
